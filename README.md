# ULTIMATE TIC TAC TOE

A Java-based desktop game featuring Classic and Ultimate Tic-Tac-Toe.

## Features

- Classic Tic-Tac-Toe
- Ultimate Tic-Tac-Toe
- Multiple board sizes
- Time-Mode championships
- Interactive graphical user interface
- Player turn and win detection

## Technologies Used

- Java
- Java Swing
- AWT

## Purpose

To practice object-oriented programming, game logic, and desktop application development.
